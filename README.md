# Personal IPTV / TVBox Config

Private configuration based on your working JSON.

- Base config: `tvbox.json`
- Auto-updated Chinese live sources (Mainland / Taiwan / Singapore focused) generated by GitHub Actions
- Final lives are written into `tvbox.json` and also available as standalone `lives/chinese.m3u`

## How to use
Subscribe the raw address of `tvbox.json` in your player (or use a GitHub proxy/mirror during blockade).

Example raw (replace with proxy if needed):
`https://raw.githubusercontent.com/RyuKyou/personal-iptv-config/main/tvbox.json`

## Update frequency
GitHub Actions runs daily to refresh live sources from public maintained repositories.
